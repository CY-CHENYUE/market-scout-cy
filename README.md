# market-scout-cy

市场调研与机会发现 skill。它把人工调研里的"搜数据、看评论、做表格、写报告、凭经验判断"整理成一套固定流程,让运营只输入一句需求,就能得到一份可复用的机会评估与竞品作战地图。

示例输入:

```text
分析美国浴缸漆市场
```

输出会围绕这些问题展开:

- 这个市场有多大、增长怎么样、价格带在哪里?
- 头部竞品是谁,他们怎么定价、怎么讲卖点、用户为什么差评?
- 用户真正想解决什么问题,哪些需求还没被满足?
- 哪些关键词、颜色、功能、场景正在出现机会?
- 这个机会能不能做,如果做应该从哪个角度切入?

## 不是只做 Amazon

这个 skill 的本质是**市场调研与机会发现**,不局限于 Amazon。

它可以用于:

- 平台电商:Amazon、Walmart、eBay、Etsy、TikTok Shop、Temu、Shein 等
- 独立站/DTC:Shopify 品牌站、品牌官网、落地页、测评站
- 内容与趋势平台:Google Trends、Reddit、TikTok、YouTube、Pinterest、Instagram
- 线下/行业市场:Home Depot、Lowe's、Costco、B2B 目录、行业报告、渠道资料
- 用户需求研究:评论、论坛、问答、社媒讨论、测评内容、客服/售后样本

为什么文档里经常出现 Amazon?

因为 Amazon 是美国电商品类调研里最常见、数据最密集的样本场景,适合做竞品矩阵、价格带、评论需求和 listing 策略。但当用户指定别的平台或非电商市场时,skill 应该按用户指定的平台和市场来跑;没有指定时,才默认用"美国电商市场 + Amazon US 作为代理样本"起步。

## 它怎么工作

核心思路是两段式漏斗:

```text
一句话需求
  -> 判断任务类型
  -> Stage 1 选品雷达:扫多个赛道,找值得深挖的方向
  -> Stage 2 竞品作战地图:深挖一个市场/品类
  -> 输出机会评分、进入角度、数据缺口
```

### Stage 1:选品雷达

当用户输入"帮我找机会"、"扫一圈漆类赛道"、"不知道做什么品类"时,先跑选品雷达。

它会批量扫描候选赛道,看:

- 需求强不强
- 增长是否明显
- 竞争是否过热
- 是否有空白细分
- 价格和利润空间是否值得做
- 是否匹配自己的供应链、工艺、内容或渠道能力

最后输出一张候选池表,让人挑 1-2 个赛道进入深挖。

### Stage 2:竞品作战地图

当用户已经给出具体市场,比如"分析美国浴缸漆市场",就直接进入深挖,不先扫一圈。

作战地图包含:

- 一页结论:做/可做但需差异化/暂缓
- 市场概况:规模、增长、价格带、竞品格局
- 流量来源结构:广告、自然搜索、站外内容
- TOP 竞品矩阵:价格、评分、评论数、排名/BSR、卖点、主图、标题、差评
- 用户需求与评论分析:差评聚类、JTBD、未满足需求
- 主图、标题、卖点策略
- 关键词布局:核心词、属性词、痛点词、场景词、机会词
- 机会发现:需求信号、供给缺口、打法、风险
- 6 维机会评分:需求、增长、空当、进入、利润、护城河契合

## 人和 AI 怎么分工

AI 负责执行密集劳动:

- 搜索资料
- 摘取数据
- 整理竞品矩阵
- 聚类评论和差评
- 反推关键词、卖点、主图和标题策略
- 做初步评分和机会判断
- 标出数据缺口和置信度

人负责关键判断:

- 这个市场边界怎么定义
- 哪个平台或渠道最重要
- 自己的供应链/品牌/渠道护城河是什么
- 选哪个细分切入
- 是否需要购买工具数据做精确定档
- 最终做不做这个产品/市场

这套设计的原则是:**AI 不替人拍板,但把拍板前的证据和选项摆清楚。**

## 数据档位

| 档位 | 数据源 | 能做什么 | 边界 |
|---|---|---|---|
| T1 公网速写 | WebSearch、WebFetch、公开报告、品牌站、测评站、论坛、社媒 | 方向判断、趋势线索、竞品画像、需求聚类 | 很难拿到真实销量、搜索量、精确流量占比 |
| T2 + browsermcp | 浏览器渲染目标平台页面 | 抓取公开页面上的价格、评分、评论、主图、标题、卖点 | 受平台反爬、登录态、页面结构影响 |
| T3 + 工具/后台 | H10、JungleScout、卖家精灵、ABA、广告报表、SimilarWeb、广告库、用户自有 CSV | 搜索量、销量、GMV、关键词难度、流量结构精确定档 | 需要账号、订阅或用户提供数据 |

拿不到的数据不会硬编。报告会标:

- `待T2`:需要浏览器抓页面
- `待T3`:需要工具或后台数据
- `低置信`:只有单源、邻近代理或估算

## 怎么使用

### 1. 直接问一个具体市场

```text
分析美国浴缸漆市场
```

适合已经知道要研究什么品类时使用。skill 会直接生成竞品作战地图。

### 2. 让它先找机会

```text
帮我扫一圈美国家装 DIY 涂料类机会
```

适合还没确定品类时使用。skill 会先输出选品雷达,再建议深挖哪个赛道。

### 3. 指定平台或渠道

```text
分析 TikTok Shop 美国香氛蜡烛机会
```

```text
分析 Home Depot 上浴室翻新类产品的机会
```

```text
分析 Shopify 独立站里的低 VOC 家装涂料品牌
```

这样 skill 会把平台/渠道写进 P0 范围界定,不默认只看 Amazon。

### 4. 带上自己的数据

```text
这是 H10 导出的关键词和竞品 CSV,帮我生成美国浴缸漆竞品作战地图
```

有工具数据时,skill 会优先使用用户提供的数据校准结论。

## 配合使用的技能

`market-scout-cy` 可以独立运行。没有其它技能时,它会用内置搜索、公开网页、模板和评分模型完成一版 T1 调研。

但如果装了下面这些技能,它会在对应步骤自动增强。它们是**增强件**,不是硬依赖。

| 配合技能 | 什么时候用 | 增强什么 | 没装怎么办 |
|---|---|---|---|
| [market-researcher-cy](https://github.com/CY-CHENYUE/market-researcher-cy) | Stage 1 选品雷达、Stage 2 P1 市场盘子 | TAM/SAM/SOM、PEST、市场细分、增长趋势、消费者洞察 | 用 `reference.md` 里的市场盘子方法做轻量估算 |
| [competitive-analyst-cy](https://github.com/CY-CHENYUE/competitive-analyst-cy) | Stage 2 P2 竞品测绘、P5 机会评估 | 竞品矩阵、SWOT、定位地图、差异化机会、竞争威胁 | 用作战地图模板里的竞品矩阵和 6 维评分兜底 |
| [deep-research](https://github.com/CY-CHENYUE/deep-research) | 需要更深资料、跨来源观点、多轮追问时 | 多轮搜索、观点聚合、多源交叉验证、复杂市场脉络 | 只做 T1 轻量调研,并标注信息缺口 |
| [fact-check-cy](https://github.com/CY-CHENYUE/fact-check-cy) | Stage 2 P4 质控 | URL 健康、数字溯源、来源可信度、矛盾检测、幻觉排查 | 按 `reference.md` 的 P4 自查清单人工执行 |
| [browsermcp-cy](https://github.com/CY-CHENYUE/browsermcp-cy) | 需要抓目标平台公开页面时 | 商品页、搜索页、评论、主图、标题、评分、排名等 T2 数据 | 停在 T1 公网可见竞品集,精确字段标 `待T2` |
| content-studio-cy | 调研完成后进入 listing/内容生产 | 把作战地图里的卖点、关键词、主图策略转成 listing、图文、内容日历 | 只交付市场调研和机会地图 |

### 没装时会怎么提示

如果任务用到了某个增强能力,但本机没有对应技能,`market-scout-cy` 应该这样处理:

1. 先说明缺什么:

```text
当前没有 browsermcp-cy,所以无法直接抓目标平台商品页/评论页。
```

2. 说明影响:

```text
TOP 竞品的评分、评论数、排名、主图和原始差评会停在 T1 公网可见样本,精确字段标待T2。
```

3. 给出兜底:

```text
我会先用公开网页、测评站、品牌站和论坛完成 T1 版本。
```

4. 给出升级方式:

```text
如需升级到 T2,可安装 browsermcp-cy,地址见 技能清单.md。
```

原则是:**提示一次,继续交付;不因为缺增强技能而中断。**

### 推荐组合

日常快速调研:

```text
market-scout-cy
```

适合先判断方向,输出 T1 作战地图。

生产级市场进入判断:

```text
market-scout-cy + market-researcher-cy + competitive-analyst-cy + fact-check-cy
```

适合需要市场规模、竞品格局、机会评分和来源质控的正式报告。

平台竞品深挖:

```text
market-scout-cy + browsermcp-cy + competitive-analyst-cy
```

适合抓目标平台页面,补价格、评分、评论、主图、标题和差评。

复杂赛道深度研究:

```text
market-scout-cy + deep-research + fact-check-cy
```

适合行业信息碎片化、来源互相矛盾、需要多轮追问的市场。

从调研到内容落地:

```text
market-scout-cy + content-studio-cy
```

适合把竞品作战地图继续转成 listing、主图方向、卖点文案和内容计划。

## 适合什么结果

适合输出:

- 市场机会初筛
- 新品/新品类进入判断
- 竞品作战地图
- 用户需求和差评洞察
- 关键词与卖点方向
- 主图、标题、bullet 策略
- 后续内容生产的市场标尺

不适合直接当作:

- 无来源的精确销量报告
- 财务投资建议
- 合规认证结论
- 最终选品拍板

最终选品仍由人决定;skill 负责把证据、机会、风险和数据缺口摊开。
